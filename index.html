NumPy

What is NumPy?

NumPy (Numerical Python) provides the ndarray, an n-dimensional array in which every element has the same data type. Operations on whole arrays run in compiled C code, so they are much faster than Python loops. Pandas, SciPy, statsmodels and PyTables are all built on top of it.

Indexing and slicing

  
A slice a[start:stop:step] includes start and stops before stop. Any part can be left out, and negative numbers count from the end. In two dimensions, m[row, col] selects along each axis and m[:, 1] takes a whole column.

  

    
Try it: slice explorer
Leave a box empty to use its default. Selected positions are highlighted.

    

      
      
      
    

    

    

    

  

  
  
Boolean masks and fancy indexing

  
A comparison such as marks > 60 returns a boolean array of the same shape. Using it inside brackets keeps only the positions that are True. A list of positions (fancy indexing) picks elements in any order.

NumPy

  
Reshaping and vectorised operations

  
reshape() rearranges the same elements into a new shape; the total number of elements must not change. Passing -1 for one dimension lets NumPy compute it. .T transposes and flatten() returns a 1D copy.

  

    
Try it: reshape twelve values
a = np.arange(1, 13) holds 12 numbers. Choose how many rows.

    

    
    

    

  

  
Vectorisation and universal functions

  
Arithmetic operators work element by element on arrays of the same shape, and universal functions (ufuncs) such as np.sqrt, np.exp and np.sin apply to every element without a loop.

  
  
  





  
NumPy

  
Broadcasting

  
Broadcasting lets NumPy combine arrays of different shapes. Shapes are compared from the right; two sizes are compatible when they are equal or one of them is 1. The smaller array is then treated as if it were repeated to match, without copying data.

  

    
Try it: what gets stretched?

NumPy

  
Aggregation and the axis argument

  
Functions such as sum, mean, max and std reduce an array. With no axis the whole array becomes one value. axis=0 runs down the rows, giving one result per column; axis=1 runs across the columns, giving one result per row.

Series and DataFrame

  
Pandas works with labelled, tabular data. A Series is one-dimensional: values with an index of labels. A DataFrame is two-dimensional: a table whose columns can each have their own type. Both are built on NumPy arrays.

df["col"] returns one column as a Series, and df[["a", "b"]] returns a DataFrame. For rows, loc selects by label and includes the end of a slice; iloc selects by integer position and excludes it.

Missing data, merging and concatenating

  
Missing values appear as NaN (or None for text). isnull() finds them, fillna() replaces them and dropna() removes rows containing them. pd.merge() joins two tables on a key column, like an SQL join; pd.concat() stacks tables.

SciPy

  
Probability distributions

  
norm(loc, scale) is the normal distribution with mean loc and standard deviation scale. Its PDF is the height of the curve at x (a density, not a probability); its CDF is the probability P(X ≤ x), the area to the left; its PPF is the inverse of the CDF.

  

    
Try it: daily rainfall
Rainfall is approximately normal. Move x and watch the shaded area, which is the CDF.

    

      
      
      
    

    
    

    

  

  
  
Shape of a distribution

  
Skewness measures asymmetry: 0 is symmetric, positive means a longer right tail, negative a longer left tail. Kurtosis (excess, as SciPy reports it) compares tail weight with the normal distribution, for which it is 0. As a rule of thumb, |skewness| < 0.5 is close to symmetric.

Hypothesis testing

  
A test starts from a null hypothesis H₀ of no difference. The p-value is the probability of seeing a result at least this extreme if H₀ were true. If p is below the chosen significance level (usually 0.05), reject H₀.

SciPy

  
FFT, image processing and special functions

  
The Fourier transform decomposes a signal into the frequencies it contains, moving from the time (or spatial) domain to the frequency domain. Peaks in the magnitude spectrum reveal the dominant frequencies; the same idea is used to filter images.

  
  
scipy.ndimage treats an image as an array. The Sobel filter responds to changes in intensity (edges); binary erosion shrinks white regions.

  
  
The gamma function extends the factorial to real numbers: Γ(n) = (n − 1)! for positive integers. It appears in many probability distributions.

statsmodels

  
Time series forecasting with ARIMA

  
ARIMA(p, d, q) combines three ideas. AR(p): the next value depends on the previous p values. I(d): the series is differenced d times to remove a trend. MA(q): the next value also depends on the previous q forecast errors.

  
  
Choose d by differencing until the series has no trend; choose p and q by comparing the AIC reported in res.summary() for a few candidate orders, and keep the lowest.

NetworkX

  
Graphs with NetworkX

  
A graph is a set of nodes (entities such as people, cities or web pages) joined by edges (connections). Edges may be directed and may carry a weight such as distance or cost. Typical applications are social networks, transport routes, protein interactions and citation networks.

Degree centrality is the fraction of other nodes a node is directly connected to, a simple measure of importance.

  





  
NetworkX

  
Shortest paths with Dijkstra's algorithm

  
Dijkstra's algorithm finds the path of least total weight from a source node. It repeatedly takes the closest unvisited node and updates the distances to its neighbours. Weights must not be negative.

PyTables

  
Hierarchical data with PyTables

  
PyTables stores data in HDF5 files, which are organised like a file system: groups act as folders and hold tables (rows of typed records) and arrays (NumPy data). Data is read from disk as needed, so files can be much larger than memory, and compression and fast queries are built in.

Common errors and fixes

  
  

    
ValueError: operands could not be broadcast together
The shapes are incompatible. Compare them from the right; each pair must be equal or contain a 1. Use reshape or [:, None] to add an axis.

    
ValueError: cannot reshape array of size 12 into shape (5,3)
The new shape must contain the same number of elements. Use -1 for one dimension to let NumPy compute it.

    
Changing a slice changed the original array
Slices are views that share memory. Use .copy() when you need an independent array.

    
KeyError when selecting a column
The name does not match exactly; check df.columns.tolist() for spelling, case and trailing spaces.

    
ValueError: The truth value of a Series is ambiguous
Use & and | instead of and/or, with brackets around each condition.

    
SettingWithCopyWarning
You modified a filtered slice. Use df.loc[condition, "col"] = value, or take .copy() of the subset first.

    
ImportError: Missing optional dependency 'openpyxl' or 'tables'
Excel needs openpyxl, Parquet needs pyarrow and HDF5 needs PyTables (pip install tables).

    
LinAlgError: Matrix is singular
The equations are dependent (determinant 0), so there is no unique solution. Check for a row that is a multiple of another.

    
ValueError: f(a) and f(b) must have different signs from brentq
The interval must bracket a root. Plot the function or try different limits.

    
OLS slope comes out as the intercept
sm.OLS does not add an intercept. Wrap X in sm.add_constant(), or use the formula API.

    
SymPy: NameError: name 'x' is not defined
Declare symbols first: x = sp.symbols("x").

    
NetworkX: NetworkXNoPath
No directed path exists between the nodes. Check edge directions or use nx.Graph() for an undirected graph.

    
PyTables: ClosedNodeError or ClosedFileError
The file was closed before the node was used. Do the work inside a with tb.open_file(...) as h5: block.
